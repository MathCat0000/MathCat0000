## About

I build web interfaces and small software systems with a focus on clarity,
measurability and verifiable outcomes.

My work combines frontend engineering with product thinking: understanding
requirements, modelling ownership and state, handling failure modes, and
validating results through tests, accessibility checks, builds and real usage.

Based in Italy. Open to remote collaboration across Europe, EMEA and worldwide.

## Selected Work

### Personal Profile

An evidence-aware profile system that separates observed outcomes from durable
skill evidence and keeps changes explicit and reviewable.

### Opportunity Engine

A local, auditable engine for discovering and evaluating structured professional
opportunities without turning rankings into automatic decisions.

### Event Engine

A deterministic workflow for reconciling events, preserving source provenance
and deriving a calendar only from explicitly confirmed commitments.

## How I Work

- Start from the user or product requirement.
- Make ownership, state transitions and failure modes explicit.
- Prefer small, testable changes over broad abstractions.
- Treat accessibility, reliability and measurement as part of the feature.
- Distinguish demonstrated capability from current learning.
- Document decisions so the result can be inspected and reproduced.

## Principles

> Good software is not only code that runs. It is code whose behaviour,
> constraints and evidence can be understood by somebody else.

I value practical proof over technology lists: a working repository, a clear
explanation, a changed requirement, a diagnosed failure and a verified result.

## Current Direction

Building toward a stronger frontend and product engineering profile through
focused React and TypeScript work, deeper testing and accessibility practice,
and full-stack projects that produce visible, reproducible evidence.
